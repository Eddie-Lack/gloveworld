Format

    
A .moo file starts with a 32-bit size that counts itself, rounded up to 16 bytes. Then come pairs
      of 16-bit values: the frame number, and the controller's button word from that frame. A frame of
      FFFF ends the list. All values are big-endian. The game starts reading at frame 9, matches each
      frame exactly, and leaves the level 20 frames after the last event.

    
In the ROM, the recordings sit one after another at 0x77BBE0, one for each level number up to
      43. Save ROM writes them back in the same 0x2240-byte space; that area is outside the header checksum.
